# WORLDLOOP

A responsive learning-community website for discovering short lessons and sharing useful knowledge.

## Included
- Responsive landing page and lesson discovery interface
- Supabase email sign-up, login, logout and password-reset email request
- Lesson submissions (held as `pending` until moderator approval)
- Save lessons, mark lessons learned and report content
- Supabase SQL migration with row-level security policies

## Before launch
This is an upload-ready starter, not a live hosted website. Follow `SETUP.md` to run the database migration, configure authentication URLs, deploy the static site and test the complete flow. Public user-generated content requires active moderation. A responsible adult should oversee any account/service setup that requires an adult account holder and all public moderation.
